# 一起学 — Chinese Together

สื่อภาษาจีนเสริมสำหรับมัธยมศึกษา ต้นแบบ HTML/CSS/JavaScript ไม่ต้องติดตั้ง dependencies
เปิด `dist/index.html` หรือใช้ static HTTP server

- หน่วยตัวอย่าง 20–30 พร้อมคำศัพท์ เสียงอ่านจากอุปกรณ์ และภารกิจ
- เทอม 1 เริ่มต้นบท 21–25; เทอม 2 บท 26–29; ปรับในโหมดครูได้
- ตัวช่วยสามระดับและคลังพื้นฐาน
- เก็บความก้าวหน้าและการจัดเทอมใน localStorage เฉพาะเบราว์เซอร์ ไม่มีบัญชีนักเรียน
- เนื้อหาแต่งขึ้นใหม่เพื่อสาธิต ยังไม่จับคู่กับสารบัญ 发展汉语 1上 ฉบับที่ใช้จริง
- เสียงอ่านต้องมีเสียงภาษาจีนในระบบปฏิบัติการ / เบราว์เซอร์
