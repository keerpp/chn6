# 一起学 — Chinese Together

เว็บไซต์สื่อภาษาจีนเสริมสำหรับมัธยมศึกษา (เริ่มต้น–HSK 3) ใช้ Worker และ R2 เก็บเอกสารการตั้งค่าห้องเรียนร่วมกัน

## ใช้งาน
- ครู: ปุ่ม **จัดการห้องเรียน** แสดงเฉพาะเจ้าของ Site ที่ลงชื่อเข้าใช้ แก้การเปิด/ซ่อนหน่วย จัดเทอม ประกาศ เนื้อหาและพินอิน งานมอบหมาย และวันส่งงาน แล้วกดบันทึก
- ครูเปิดมุมมองนักเรียนเพื่อตรวจสอบสิ่งที่นักเรียนเห็นได้ พิมพ์ใบงานและใช้ตัวจับเวลาได้
- นักเรียน: เห็นเฉพาะบทเปิดเรียน รวมถึงห้องฝึกและหน้าความก้าวหน้า ข้อมูลการเปิดบทเรียนอัปเดตเมื่อโหลดหน้าหรือภายใน 30 วินาที
- พินอินคำถามและตัวเลือกคำตอบแสดงทุกระดับตัวช่วย
- ฝึกคำศัพท์ ฟังแล้วเลือก เรียงประโยค ภารกิจ อัดเสียงฟังตนเอง และทบทวนคำที่ตอบผิด
- ผลฝึก ประโยคที่ร่าง และคำทบทวนเก็บเฉพาะเบราว์เซอร์ ไม่มีระบบส่งงานออนไลน์หรือคะแนนรวมรายห้อง
- การอัดเสียงต้องได้รับอนุญาตไมโครโฟน เสียงไม่อัปโหลดและหยุดอัดเมื่อครบ 60 วินาที

## เนื้อหาและเสียง
หน่วย 20–30 เป็นตัวอย่างแต่งขึ้นใหม่ ยังไม่ได้จับคู่กับสารบัญ 发展汉语 1上 ฉบับที่ใช้จริง ครูแก้ไขเนื้อหาได้
ไฟล์ `web/audio/tone1.mp3`–`tone4.mp3` เป็นเสียงสังเคราะห์ภาษาจีนกลาง (妈 麻 马 骂) ที่เตรียมผ่าน Google Translate TTS วันที่ 2026-11-22 ไม่ใช่เสียงผู้สอน เสียงช้าใช้ playbackRate โดยรักษาระดับเสียง เส้นกราฟและเสียงดนตรีสาธิตเป็นแบบจำลองทิศทางวรรณยุกต์ ไม่ใช่ผลวัดหรือเสียงอ่าน คำอื่นใช้ speechSynthesis โดยเลือก zh-CN ก่อนภาษา zh อื่น

## พัฒนาและตรวจสอบ
- `npm run build` สร้าง Worker พร้อมไฟล์เว็บและเสียงใน `dist/server/index.js`
- `npm test` ตรวจสิทธิ์ครู การซ่อนบทเรียนจาก API การบันทึกและตรวจรุ่นข้อมูล พินอินและเส้นทางผู้เรียน
- `npm run dev` ใช้เซิร์ฟเวอร์ทดสอบกับ R2 จำลองในหน่วยความจำ ไม่มีการจำลองบัญชีครู

## การเก็บข้อมูลและสิทธิ์
`.openai/hosting.json` ผูก BUCKET สำหรับเอกสาร `classroom/config-v2.json` การบันทึกใช้ ETag เพื่อป้องกันเขียนทับพร้อมกัน
API ตรวจอัตลักษณ์ที่แพลตฟอร์มยืนยันและอนุญาตเจ้าของ Site เท่านั้น ไม่ใช้โหมด UI เป็นการตรวจสิทธิ์ ตรวจ Origin สำหรับการเขียนและตรวจข้อมูลก่อนบันทึก
สิทธิ์เข้าเว็บไซต์ยังคง owner-private ตามเดิม ต้องจัดสิทธิ์ผู้ชมก่อนให้นักเรียนเข้าถึง การเปิดบทเรียนไม่เปลี่ยน audience
